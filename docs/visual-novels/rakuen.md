# Rakuen ~Ai Kawarazu na Boku. no Baai~

## GNU/Linux

You will need to juggle between two prefixes, proton-ge with runner `proton-ge 11-3` and a 32bit wineprefix with `wine 11.13` as runner (Any other 11 wine runner should also work).
Make sure to have the Windows pack fonts in both prefixes and run the game with Japanese Locale: `LANG=ja_JP.UTF-8`

### Installation

1. Mount disc 1 with [cdemu](/linux/cdemu).
2. Once it asks for disc 2, force stop the installer.
3. Mount disc 2.
4. Copy the contents to the installation folder.

### Run the game

1. Use mainly the proton-ge prefix since it is the more stable and plays the videos.
2. Set `rakuen.exe` as executable.
3. There are two or three times where the game will crash due to a unsupported emoji in the textbox.
4. When the game crashes swap to the 32 bit prefix and get past the line in the textbox and save.
5. You can keep going or go back to the proton-ge prefix, however at least for me the game crashed constantly with wine prefixes.
