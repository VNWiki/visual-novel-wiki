# Tsuyukusa Euphoria

### GNU/Linux

## Installation

Create a new prefix with runner `proton-ge 10.34`:

1. Runner: `proton-ge 10.34`
2. Install dotnet48 with Winetricks or Protontricks.
3. install the game: Run with the new prefix the `C2Fsetup.msi` installer. Proceed with the installation by default. The game will be installed inside the prefix in program files.
4. Go to the game folder into the folder `objcets/lib` and copy all the .dll into the same level as the main exe `c2f.exe`.
5. Run the game with the prefix with `c2f.exe`.
